# 동행컴퍼니 웹사이트

동행컴퍼니의 인스타그램 퍼스트 로컬 마케팅 구조를 설명하는 반응형 브랜드/세일즈 웹사이트입니다.

## 핵심 흐름

`발견 → 확산 → 검색 → 확신 → 방문`

## 가격

- 월 55만원
- VAT 포함
- 최소 3개월
- 이후 1개월 단위 연장

## 개발

```bash
npm install
npm run dev
```

## 검증

```bash
npm run verify
```

최종 배포 전에는 GitHub Actions에서 동일한 `npm run verify` 전체 검증을 통과한 커밋만 운영에 반영합니다.

실제 로고, 상담 URL, 회사 법적 정보, 공개 가능한 실사/릴스 자산은 제공 후 `content/site.ts` 및 `public/` 자산을 교체합니다.
